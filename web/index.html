    Compute

    compute.mapreduce@1 sends the load case to two machines with different processors. Each runs physics.fem@1, a plane-stress solver written so that every platform gets the same bits, and signs what it got with its own key.

    Certify

    cert.issue@1 signs only when two independent keys report the same output hash. The certificate pins the solver source by its SHA-256 and names the input and output as ce-blob content ids.

    Check

    cert.verify@1 is the same Rust code, compiled to WebAssembly. It runs here, offline, with no server: signatures, hashes, the closed-form bound and a full re-run of the solver.
